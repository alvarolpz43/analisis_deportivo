1. Teorema de Bayes: Probabilidad Condicional y Actualización de Creencias

Actualiza la probabilidad a priori de un evento deportivo tras observar evidencia contextual en el partido.

Inferencia Bayesiana
$$P(A \mid B) = \frac{P(B \mid A) \cdot P(A)}{P(B)} = \frac{P(B \mid A) \cdot P(A)}{P(B \mid A)P(A) + P(B \mid \neg A)P(\neg A)}$$
  • P(A) Probabilidad a Priori del evento objetivo (frecuencia base en 3.800 partidos).
  • P(B) Probabilidad Marginal de la Evidencia (tasa histórica de la condición observada).
  • P(B|A) Verosimilitud (Likelihood): probabilidad de que la evidencia ocurra cuando el evento es verdadero.
  • P(A|B) Probabilidad a Posteriori: creencia actualizada del evento tras verificar la evidencia.
Ver contextualización por Integrante:
$$P(\text{FTR} = \text{H} \mid \text{HST} > 5) = \frac{P(\text{HST} > 5 \mid \text{FTR} = \text{H}) \cdot P(\text{FTR} = \text{H})}{P(\text{HST} > 5)} = 65.2\%$$
src/analytics/inferential_engine.py 
# 1. Definición de máscaras booleanas empíricas
event_mask = df['FTR'] == 'H'          # Evento A: Victoria Local
cond_mask  = df['HST'] > 5             # Condición B: Tiros al arco > 5

# 2. Conteo de frecuencias en tabla de contingencia 2x2
a = int((event_mask & cond_mask).sum())     # A y B verdaderos (738)
b = int((~event_mask & cond_mask).sum())    # No A y B (393)
c = int((event_mask & ~cond_mask).sum())    # A y No B (990)
d = int((~event_mask & ~cond_mask).sum())   # No A y No B (1.679)

# 3. Cálculo del Teorema de Bayes
prior_A = float(event_mask.mean())           # P(A) = 0.4547 (45.5%)
prob_B  = float(cond_mask.mean())            # P(B) = 0.2976 (29.8%)

likelihood = a / (a + c)                     # P(B|A) = 738 / 1.728 = 0.4271
posterior  = (likelihood * prior_A) / prob_B # P(A|B) = a / (a + b) = 0.6525 (65.2%)

bayes_factor = posterior / prior_A           # Multiplicador: x1.43 de incremento

2. Distribución Hipergeométrica: Muestreo Finito sin Reemplazo

Modela la probabilidad de observar exactamente $x$ éxitos en una muestra de $n$ elementos extraídos sin reemplazo.

Combinatoria & Probabilidad Discreta
$$P(X = x \mid N, r, n) = \frac{\binom{r}{x} \binom{N - r}{n - x}}{\binom{N}{n}}$$
$$E[X] = n \frac{r}{N}, \quad \operatorname{Var}(X) = n \frac{r}{N} \left(1 - \frac{r}{N}\right) \left(\frac{N - n}{N - 1}\right)$$
  • N Tamaño total de la población finita (ej. Tiros totales del local $N = \text{HS}$).
  • r Cantidad de éxitos en la población (ej. Tiros al arco $r = \text{HST}$).
  • n Tamaño de la muestra auditada o extraída sin reemplazo.
  • x Cantidad exacta de éxitos observados dentro de la muestra.
  • (N-n)/(N-1) Factor de corrección para poblaciones finitas en la varianza.
  • n < 0.05N Criterio Larson & Farber: si la muestra es menor al 5% de la población, se puede aproximar por la distribución binomial con $p = r/N$.
src/analytics/inferential_engine.py 
from scipy.stats import hypergeom
import math

def calculate_hypergeometric(N: int, r: int, n: int, x: int):
    # Instancia de distribución hipergeométrica en SciPy:
    # M = Población (N), n = Éxitos totales (r), N = Muestra (n)
    dist = hypergeom(M=N, n=r, N=n)

    pmf_exact = float(dist.pmf(x))           # P(X = x) Exacta
    cdf_leq   = float(dist.cdf(x))           # P(X <= x) Acumulada
    sf_geq    = float(dist.sf(x - 1))        # P(X >= x) Supervivencia

    # Esperanza y varianza con factor de corrección finita
    expected_val = float(n * (r / N))
    variance = float(n * (r / N) * ((N - r) / N) * ((N - n) / (N - 1))) if N > 1 else 0.0
    std_dev  = math.sqrt(max(0.0, variance))

    return {"pmf": pmf_exact, "cdf": cdf_leq, "mean": expected_val, "var": variance}

3. Prueba de Independencia Chi-Cuadrado ($\chi^2$), Odds Ratio e IC al 95%

Evalúa si la relación observada es estadísticamente significativa o producto del azar muestral.

Estadística Inferencial
$$\chi^2 = \sum_{i=1}^2 \sum_{j=1}^2 \frac{(O_{ij} - E_{ij})^2}{E_{ij}}, \quad E_{ij} = \frac{\text{Total Fila}_i \cdot \text{Total Col}_j}{N_{\text{total}}}$$
$$\text{OR} = \frac{a \cdot d}{b \cdot c}, \quad \text{IC}_{95\%}(\text{OR}) = \exp\left(\ln(\text{OR}) \pm 1.96 \cdot \sqrt{\frac{1}{a} + \frac{1}{b} + \frac{1}{c} + \frac{1}{d}}\right)$$
  • O_{ij} Frecuencia conjunta observada en la celda $(i, j)$ de la tabla $2 \times 2$.
  • E_{ij} Frecuencia esperada bajo la hipótesis nula de independencia ($H_0$).
  • Odds Ratio Razón de momios: cuánto se multiplican las posibilidades de ganar.
  • p-valor Probabilidad de obtener una discrepancia igual o mayor bajo $H_0$ ($p < 0.05$).
src/analytics/inferential_engine.py 
from scipy.stats import chi2_contingency
import numpy as np

# 1. Tabla de contingencia 2x2
table = np.array([[a, b], [c, d]])

# 2. Prueba de independencia Chi-Cuadrado
chi2_stat, p_val, dof, expected = chi2_contingency(table)
is_significant = bool(p_val < 0.05)

# 3. Odds Ratio (OR) e Intervalo de Confianza al 95%
odds_ratio = (a * d) / (b * c)
se_log_or  = math.sqrt(1/a + 1/b + 1/c + 1/d)
ci_lower   = math.exp(math.log(odds_ratio) - 1.96 * se_log_or)
ci_upper   = math.exp(math.log(odds_ratio) + 1.96 * se_log_or)

4. Modelo Poisson Bivariado: Goles Esperados (xG) y Marcadores Exactos

Computa la intensidad ofensiva/defensiva de cada club para predecir la matriz de marcadores y Más/Menos 2.5 goles.

Procesos Estocásticos
$$P(G_H = i, G_A = j) = \frac{\lambda_H^i e^{-\lambda_H}}{i!} \times \frac{\lambda_A^j e^{-\lambda_A}}{j!}$$
$$\lambda_H = \frac{\text{GF}_H}{\overline{\text{GF}}_L} \cdot \frac{\text{GA}_A}{\overline{\text{GA}}_L} \cdot \mu_H, \quad P(\text{Más de 2.5}) = 1 - \sum_{i+j \le 2} P(G_H = i, G_A = j)$$
  • \lambda_H, \lambda_A Tasa media de goles esperados (xG) de local y visitante.
  • \mu_H = 1.45 Promedio histórico de goles marcados por clubes locales en La Liga.
  • \text{GF}_H, \text{GA}_A Capacidad goleadora del local frente a la vulnerabilidad defensiva del visitante.
src/models/predictor.py 
from scipy.stats import poisson

# 1. Parámetros Poisson de intensidad (xG)
lambda_h = max(0.4, (h_stat['gf'] / 1.3) * (a_stat['ga'] / 1.3) * 1.45)
lambda_a = max(0.3, (a_stat['gf'] / 1.1) * (h_stat['ga'] / 1.3) * 1.10)

# 2. Convolución bivariada para marcadores i vs j
score_matrix = []
prob_over_2_5 = 0.0
for i in range(5):
    for j in range(5):
        p_ij = float(poisson.pmf(i, lambda_h) * poisson.pmf(j, lambda_a))
        if (i + j) > 2.5:
            prob_over_2_5 += p_ij
        score_matrix.append({"score": f"{i} - {j}", "probability": p_ij})

5. Regresión Logística Multinomial: Función Softmax en Machine Learning

Convierte el vector de 16 variables rodantes sin filtración temporal en una distribución probabilística multiclase $\{H, D, A\}$.

Machine Learning
$$P(Y = c \mid \mathbf{x}) = \frac{e^{\mathbf{w}_c^T \mathbf{x} + b_c}}{\sum_{k \in \{H, D, A\}} e^{\mathbf{w}_k^T \mathbf{x} + b_k}}, \quad c \in \{0: \text{H}, 1: \text{D}, 2: \text{A}\}$$
  • \mathbf{x} \in \mathbb{R}^{16} Vector de características rodantes normalizadas (StandardScaler).
  • \mathbf{w}_c, b_c Pesos y sesgo aprendidos por optimización L-BFGS multiclase.
  • \sum P(Y=c) = 1.0 Garantía estricta de coherencia axiomática de Kolmogorov.

$$P(H) = w_{\text{H2H}} \cdot P_{\text{H2H}}(H) + (1 - w_{\text{H2H}}) \cdot P_{\text{10y\_casa}}(H)$$
$$w_{\text{H2H}} = \min(0.65, n_{\text{partidos}} \times 0.08), \quad \text{Cuota Justa}_c = \frac{1}{P(c)}$$
  • w_{\text{H2H}} Factor de credibilidad bayesiana (shrinkage): crece conforme hay más enfrentamientos directos.
  • \text{Cuota Justa} Cuota sin margen de casa de apuestas (Fair Odds = $1 / P$).

7. Distribución Binomial: Eventos Independientes y Conteo de Goles

Modelado estocástico formal para variables donde cada ensayo es independiente entre sí con probabilidad de éxito constante.

Distribución Discreta
$$P(X = k) = \binom{n}{k} p^k (1 - p)^{n - k} = \frac{n!}{k!(n - k)!} p^k (1 - p)^{n - k}$$
$$E[X] = n \cdot p, \quad \operatorname{Var}(X) = n \cdot p \cdot (1 - p), \quad \sigma = \sqrt{n \cdot p \cdot (1 - p)}$$
  • n Número total de ensayos independientes (ej. serie de partidos analizados).
  • p Probabilidad empírica de éxito en cada ensayo individual.
  • k Número de éxitos buscados (ej. cantidad de goles o partidos con victoria).
modelo.py & inferential_engine.py 
from scipy.stats import binom
import math

# 1. Instancia del modelo binomial (n ensayos, p probabilidad)
dist = binom(n, p)

# 2. Función de Masa de Probabilidad (PMF) y Acumulada (CDF)
prob_exacta = float(dist.pmf(k))
prob_acum   = float(dist.cdf(k))

# 3. Momentos teóricos de la distribución
esperanza   = float(n * p)
varianza    = float(n * p * (1.0 - p))
sigma       = math.sqrt(varianza)

8. Validación de Confiabilidad: Desviación Estándar (s) & Contraste Bilateral de Localía

Demostración inferencial de baja dispersión sobre 3.800 partidos y rechazo de la hipótesis nula de ausencia de ventaja local.

Inferencia Paramétrica
$$s = \sqrt{\frac{1}{N - 1} \sum_{i=1}^{N} (x_i - \bar{x})^2}, \quad Z = \frac{\hat{p} - p_0}{\sqrt{\frac{p_0(1 - p_0)}{N}}}$$
$$H_0: p = 0.5 \quad \text{vs} \quad H_1: p \neq 0.5, \quad \text{IC}_{95\%} = \hat{p} \pm 1.96 \sqrt{\frac{\hat{p}(1 - \hat{p})}{N}}$$
  • s Desviación estándar muestral. Valores pequeños ($s \approx 1.2$) denotan confiabilidad de las estimaciones.
  • Z = -5.59 Estadístico de prueba tipificado; con $p < 0.0001$ se rechaza $H_0$.
  • p_0 = 0.5 Parámetro nulo de equidad entre victoria local y no ganar.

9. Distribución de Poisson: Conteo en Intervalos Continuos (Larson & Farber Cap. 4)

Modela eventos raros en intervalos de tiempo continuo (90 minutos) y define el rango usual $[\mu - 2\sigma, \mu + 2\sigma]$.

Larson & Farber Cap. 4
$$P(x) = \frac{\mu^x e^{-\mu}}{x!}, \quad \operatorname{Var}(x) = \sigma^2 = \mu, \quad \sigma = \sqrt{\mu}$$
$$\text{Rango Usual} = [\mu - 2\sigma, \; \mu + 2\sigma], \quad x \notin [\mu \pm 2\sigma] \iff \text{Inusual } (P < 0.05)$$
  • \mu Media de ocurrencias en el intervalo continuo (ej. $\mu = 1.45$ goles locales por partido).
  • x Conteo discreto de eventos observados ($x = 0, 1, 2, \dots$).
  • \sigma = \sqrt{\mu} Desviación estándar exacta según la identidad de Poisson.
  • \text{Rango Usual} Criterio de Larson & Farber: valores a más de 2 desv. estándar son inusuales.
src/analytics/inferential_engine.py 
from scipy.stats import poisson
import math

def calculate_poisson(mu: float, x: int):
    dist = poisson(mu)
    variance = mu
    std_dev  = math.sqrt(mu)
    
    # Rango usual Larson & Farber [mu - 2*sigma, mu + 2*sigma]
    usual_min = max(0.0, mu - 2.0 * std_dev)
    usual_max = mu + 2.0 * std_dev
    is_usual  = bool(usual_min <= x <= usual_max)
    
    return {"pmf": dist.pmf(x), "std_dev": std_dev, "is_usual": is_usual}

10. Distribución Normal Estándar, Valor z y 4 Casos de Área (Larson & Farber Cap. 7)

Tipificación z y cálculo de áreas bajo la curva estándar para evaluación de rendimiento deportivo.

Larson & Farber Cap. 7
$$z = \frac{X - \mu}{\sigma}, \quad f(x) = \frac{1}{\sigma \sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{x - \mu}{\sigma}\right)^2}$$
$$\text{Caso 1: } P(Z < z) = \Phi(z), \quad \text{Caso 2: } P(Z > z) = 1 - \Phi(z)$$ $$\text{Caso 3: } P(-|z| < Z < |z|) = 2\Phi(|z|) - 1, \quad \text{Caso 4: } 2(1 - \Phi(|z|))$$
  • z Número de desviaciones estándar que separan a $X$ de la media $\mu$.
  • \text{Regla Empírica} 68.26% en $\mu \pm 1\sigma$, 95.44% en $\mu \pm 2\sigma$, 99.73% en $\mu \pm 3\sigma$.
  • \Phi(z) Función de distribución acumulada (CDF) de la normal estándar $N(0, 1)$.
src/analytics/inferential_engine.py 
from scipy.stats import norm

def calculate_normal(value: float, mean: float, std_dev: float):
    z = (value - mean) / std_dev
    # 4 Casos de Larson & Farber
    area_left  = float(norm.cdf(z))            # Caso 1: P(Z < z)
    area_right = float(1.0 - area_left)       # Caso 2: P(Z > z)
    area_between = float(2.0 * norm.cdf(abs(z)) - 1.0) # Caso 3
    area_tails   = float(1.0 - area_between)   # Caso 4
    return {"z_score": z, "case_1": area_left, "case_2": area_right}
